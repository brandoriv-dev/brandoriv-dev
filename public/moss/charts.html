Chart contract and host coverage

MossTheme supplies colors, typography, density, geometry, and motion. The neutral preset uses locally bundled Geist Variable; the five product themes retain their values and system fallbacks. Apache ECharts loads from the local bundle only when a chart needs rendering.

Set preset or assign .config from getChartExample(id); replace rows through .data. Keep the summary accurate for product data. Attributes loading, error, and disabled expose explicit states; missing numeric values produce partial or empty evidence.

Tab reaches selection controls, the plot, and Chart data. Arrow keys, Home, and End inspect points. Native range, series, and slice selectors support keyboard and touch. Exact values remain available without hover; long data and code scroll inside their own regions.

Hosts own fetching, cancellation, recovery, and narrative accuracy. Summaries and exact tables remain available immediately; SVG rendering is deferred until near the viewport. moss-chart-ready fires only after an actual render; moss-chart-select reports { index, key, value }. Disconnect disposes renderer resources, and inherited theme and size changes refresh visible plots.

Intended hosts are plain web, Blazor web, and .NET MAUI Blazor Hybrid using the shared web renderer. Browser verification covers Chromium desktop and phone viewports; native-device and WebView coverage require separate host checks. Native XAML parity and Linux-native MAUI packaging are outside this contract.
